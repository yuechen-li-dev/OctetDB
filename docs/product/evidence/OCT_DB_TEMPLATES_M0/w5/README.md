# W5 template-authored control

`query.template.oct` keeps PERF-M4's durable OctetDB Dataset authority and application-owned rebuild boundary. It replaces the reusable filter/take declaration with the canonical `DatabaseTemplates.FilteredView<Job>`, imports the refined Concept companion for statically admitted configuration, and retains a concrete `BespokeFilteredView` solely for structural/runtime comparison.

Generate from the two adjacent repository checkouts:

```powershell
./generate.ps1 -OctRepo C:\path\to\oct
```

The script assembles the canonical package in a temporary project, invokes the existing source-only Go backend, and removes the temporary project after generation. Catalog definitions are not copied into OctetDB source control. Generated Go is not manually edited.
